scanipy
self-hosted SAST · one-command Docker
Paste a public GitHub repository. Scanipy scans it with established analysis engines and returns findings labeled oracle-passthrough. The deterministic-core (IFDS / code-property-graph) engine is in progress and not on this path yet.

Analysis runs inside the Scanipy container and the scanned code is never executed. Findings on this path are oracle-passthrough (engine: Semgrep) and carry a weak same-source fingerprint — a stable id, not a canonical-graph claim. Byte-identical reproducibility and refactor-invariant identity are separate guarantees delivered by the deterministic-core engine, which is staged.
