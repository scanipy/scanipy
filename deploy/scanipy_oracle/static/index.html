New scans are unavailable

The legacy native scan path is disabled while the reviewed source-capture and worker replacement is connected. No repository is submitted or scanned from this page.

Existing stored scans remain available through GET /api/scan/{scan_id}. Historical records retain their original metadata; they are not upgraded to new identity or provenance guarantees by this change.

Application liveness and capability status

A live application does not mean scanning is ready. This containment is not the completed Black Hat demo, a verified native analysis environment, or evidence of refactor-invariant identity or reproducibility.

The legacy read API has no authentication. Keep access local or use your own authenticated access boundary. Existing data is not deleted.
